## Why record this

A Micro.blog theme export merges plug-in files into the generated Hugo tree. Without an inventory it can be difficult later to tell whether a template or asset was written locally, came from Bayou, or was injected by a plug-in.

When plug-ins are added, removed, upgraded, or materially reconfigured, update this file and add a short entry to `CHANGELOG.md`.
